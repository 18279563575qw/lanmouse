LanMouse 电脑端 使用说明
================================================

这个程序让手机变成无线触控板，通过家里的局域网控制这台 Windows 电脑的鼠标。
电脑端不需要安装任何东西（用系统自带的 .NET Framework）。


一、最快的用法（3 步）
------------------------------------------------
第 1 步：双击 start-server.bat
   会弹出一个黑窗口，里面显示：

       监听地址 : 0.0.0.0:8765
       认证令牌 : lanmouse
       局域网 IP:
         192.168.1.100        <-- 记住这一行

   这个窗口要一直开着，关掉就等于关闭服务。停止服务按 Ctrl+C。
   如果弹出蓝色的“Windows 已保护你的电脑”，点“更多信息” → “仍要运行”。

第 2 步：允许防火墙通过（第一次用才需要）
   双击 allow-firewall.bat，弹出“是否允许…更改”时点“是”。
   如果第 1 步之后手机已经能控制鼠标，这一步可以跳过。

第 3 步：手机端
   把 android-apk 文件夹里的 LanMouse-debug.apk 传到手机安装
   （手机需要允许“安装未知来源的应用”）。
   打开 App 后：
     - 点“搜索 Windows 设备”，或手动填写第 1 步显示的 IP；
     - 端口填 8765，令牌填 lanmouse（要和黑窗口里显示的一致）；
     - 点“应用并启用触控板”；
     - 状态栏出现“已连接 192.168.x.x:8765（UDP）”，就可以用了。

   手势：单指移动 · 轻触左键 · 长按后拖动 · 双指轻触右键 · 双指上下滚动。


二、前提条件
------------------------------------------------
1. 手机和电脑连的是同一个局域网（同一个路由器的 Wi-Fi，手机不要用流量）。
2. 电脑端窗口必须还在运行，且显示着 IP。
3. 公司、学校、酒店的 Wi-Fi 经常做设备隔离，那样手机搜不到电脑，属于网络限制。


三、遇到问题怎么看
------------------------------------------------
* 手机显示“Windows 端没有响应 …”
    - 电脑上的黑窗口还开着吗？
    - 端口、令牌和窗口里显示的完全一致吗？
    - 双击一次 allow-firewall.bat 再试。
    - 网络类型是“公用网络”时 Windows 会拦截入站连接：
      设置 → 网络和 Internet → Wi-Fi（或以太网） → 点当前网络 → 改成“专用网络”。

* 手机搜不到设备
    - 直接手动填写黑窗口里显示的“局域网 IP”。
    - 确认手机连的是同一个 Wi-Fi，且不是访客网络。

* 端口被占用、启动报错
    - 用 PowerShell 在本文件夹执行：  .\run.ps1 -Port 9000
      手机端的端口也改成 9000，令牌保持一致。

* 鼠标卡在按下状态
    - 服务端 5 秒收不到数据会自动松开按键；也可以按 Ctrl+C 重启服务端。

* 想换令牌（建议在宿舍、合租等环境换一个）
    - PowerShell 执行：  .\run.ps1 -Token "自己起一个随机字符串"
      手机端“认证令牌”填一模一样的值。


四、安全提醒
------------------------------------------------
* 服务端使用明文 UDP + 共享令牌，只适合自己家的可信局域网。
* 不要在公共 Wi-Fi（咖啡厅、机场、酒店）里开着它。
* 不要把 8765 端口映射到公网、不要做端口转发。


五、文件说明
------------------------------------------------
  start-server.bat     双击启动服务端（推荐）
  allow-firewall.bat   一键允许防火墙通过（会弹 UAC，点“是”）
  LanMouseServer.exe   服务端本体，.NET Framework 4.x，Win10/11 自带
  run.ps1              启动脚本，可改端口 / 令牌
  build.ps1 + src\     源码和编译脚本（想自己重新编译时用）
  setup-firewall.ps1   用管理员 PowerShell 手动添加防火墙规则的脚本
  android-apk\         手机端 APK（朋友已经有 App 的话可以删掉这个文件夹）
